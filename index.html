@cnguu/watermark纯 TS 水印库

零依赖、防篡改、懒加载、高性能，最低兼容 Android 6

快速开始
在线演示
GitHub

  • 零依赖

    纯 TypeScript 实现，不引入任何运行时第三方库，体积小巧。

  • 防篡改

    通过 MutationObserver 监听内联样式与节点移除，自动恢复水印。

  • 多实例

    每个实例拥有独立的 DOM 节点与观察者，互不冲突。

  • 高性能

    水印以 CSS 背景图形式平铺，resize 期间无需重绘 canvas。

  • 高可定制

    内容、字体、颜色、旋转、间距、透明度、层级、覆盖区域等均可配置。

  • 兼容性好

    仅使用 Android 6 (Chrome 44+) 支持的标准 API，无需 polyfill。
